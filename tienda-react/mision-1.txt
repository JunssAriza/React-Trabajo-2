1. ¿Qué tiene que pasar para agregar un producto ahí desde la pantalla?
Básicamente, ese formulario que creaste es como un mesero. Tú le vas dictando en las casillitas: "oye, quiero meter un teclado, cuesta tanto, hay 5". El mesero anota todo en su libretica y, ¡pum!, cuando le das al botón de agregar, sale corriendo y le tira esa nota al jefe del local (tu App.jsx). El jefe agarra la nota, la mete en la lista oficial de cosas para vender y todos felices.

2. ¿Y cómo carajos se acuerda React de que el inventario cambió?
Bueno, React tiene una memoria a corto plazo, como si tuviera un post-it pegado en la frente. Ese post-it es el famoso "Estado" (useState). Mientras no cierres la pestaña ni le des a recargar a la página (que sería como arrancarle el post-it y tirarlo a la basura), React se va a acordar de todo lo que le metas a esa lista y lo va a cuidar con su vida.

3. ¿Qué tiene que pasar para que el catálogo se actualice sin recargar la página y todo parpadee?
Aquí está el truco de magia: tienes que avisarle a React de la forma que a él le gusta. Si tú vas y metes el producto a la mala, a escondidas, React se hace el loco y no actualiza la pantalla. Tienes que usar el megáfono, que es esa función setProductos. Le gritas: "¡Oye React, toma esta lista NUEVA con el producto incluido!". Apenas React escucha eso, dice "¡Uy, hay cambios!" y redibuja la pantalla ahí mismo, en milisegundos. Cero pantallas de carga, todo al instante.

4. ¿Por qué es una pésima idea andar editando el archivo productos.js para cambiar el stock?
¡Uf! ¡Imagínate la locura! Ese archivo productos.js es como el inventario inicial con el que abriste la tienda el primer día. Está escrito en piedra. Si cada vez que un cliente se compra un mouse tú tuvieras que ir, meterte a los archivos del código, borrar un "5", poner un "4" y volver a guardar... ¡no dormirías nunca!
Además, la gente en internet no tiene forma de meterse a tus archivos para cambiarlos. Por eso, ese archivo solo te da los productos de arranque para que la tienda no se vea vacía, y ya; después de eso, el Estado es el que se encarga de la fiesta.
